# 画像の置き場所

トップページ（`/`）で使う画像を、このフォルダに置きます。**2種類**あります。

| 役割 | ファイル名 | どこに出るか |
|---|---|---|
| **画面全体の背景** | `hero.*` | トップページのタイトル画面いっぱい |
| **メニュー上部の絵** | `modal-bg.*` | メニューを開いたときの、上半分のバナー |
| **参加画面の背景** | `join-bg.*` | 生徒の参加画面（`/play`）。**無ければ `hero.*` を使います** |
| **ルーム作成画面の背景** | `room-make-bg.*` | 先生のルーム作成画面（`/teacher`）。無ければ配色のみ |

> ⚠ **ファイル名にスペースを入れないでください。**
> `join-room bg.png` のような名前は読み込まれません。上の表の名前に合わせてください。

拡張子は **`.webp` → `.jpg` → `.jpeg` → `.png`** の順に探し、最初に見つかったものを使います。
置くだけで反映されます。**サーバの再起動もコードの変更も不要です**（ブラウザを再読み込みしてください）。

どちらも無いときは、配色とSVGの挿絵で表示されます。画像が無くてもページは壊れません。

---

## `modal-bg.*` について（注意点あり）

現在置かれている `modal-bg` には、**タイトル・リボン・✕ボタンが絵として描き込まれています**。
そのためプログラム側で次の切り替えを行っています。

1. CSSで描いていたタイトルとリボンは**画面に出しません**
   （読み上げソフトと検索のため、HTMLからは消していません）
2. ✕ は絵の一部なので、**その位置に透明な操作ボタンを重ねています**

### 絵を差し替えるときは

✕ の位置が変わると、押せる場所がずれます。`styles/home.css` の
`body.has-modal-art .menu-close` にある次の変数で合わせてください。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `--close-top` | `4.6%` | 絵の上端から✕までの距離 |
| `--close-right` | `1.7%` | 絵の右端から✕までの距離 |
| `--close-w` | `7%` | ✕の大きさ（絵の幅に対する割合） |

割合で指定しているので、画面の大きさが変わってもずれません。
枠の縦横比は画像から自動で読み取ります（`--modal-art-ratio`）。

### `join-bg` の見せ方について

いまの絵には、3人の登場人物（企業経営者・原料営業・原料生産者）と、
その役割を説明する札が描かれています。カードで隠れてしまわないよう、次のように配置しています。

- カードは絵の**左〜中央（空と海）**の上に置く
- **右側に原料生産者**が見えるよう、背景を少し右に寄せる（`--join-art-pos`）
- **下側に3つの役割の札**が読めるよう、カードの高さを抑える
- カードの下から人物が中途半端にのぞく部分は、影を落として目立たなくする

寄せ具合を変えたいときは `styles/app.css` の次の値を調整してください。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `--join-art-pos` | `64% center` | 絵のどのあたりを画面に出すか。数字を小さくすると左に寄ります |

> 画面が狭いとき（タブレットの横向きなど）は、参加のしやすさを優先して
> カードを大きく出すため、人物や札は隠れます。これは意図した動作です。

### `room-make-bg` について

いまの絵は**文字や板が描かれていない教室の絵**なので、**ぼかさずそのまま**出しています。
実物のパネル（ゲームの流れ・設定のポイント）が絵の上に乗る形です。

以前の絵のように**板や黒板が描き込まれた絵**に差し替えると、実物のパネルと二重に見えます。
そのときは `styles/app.css` の `--setup-art-blur` を `6px` 程度にすると、
背景側の文字がぼけて読めなくなり、二重に見えなくなります。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `--setup-art-blur` | `0px` | 背景のぼかし。文字入りの絵なら `6px` 前後に |
| `--setup-art-pos` | `center` | 絵のどのあたりを画面に出すか |

### `modal-bg` について（続き）

**絵にタイトルや✕が入っていない画像**に差し替える場合は、
`home.css` の `body.has-modal-art .hero-copy { ... }` と
`body.has-modal-art .menu-close { ... }` の2ブロックを削除すれば、
CSSで描いたタイトルと、通常の丸い✕ボタンに戻ります。

> 絵に文字を焼き込むと、あとから文言を直したり他の言語にしたりできなくなります。
> 将来その必要が出そうなら、文字の入っていない絵にして、
> タイトルはCSS側で出す構成をおすすめします。

### `join-room.png` について

これは参加画面の**完成イメージ（モックアップ）**で、絵の中にカードやボタンまで
描き込まれています。そのまま背景にすると、本物のボタンと絵のボタンが二重に出てしまうため、
**背景としては使っていません**（デザインを合わせるための見本として置いてあります）。

参加画面の背景を専用の絵にしたい場合は、**カードやボタンが描かれていない風景だけの画像**を
`join-bg.jpg` という名前で置いてください。置かれていなければ `hero.jpg` が使われます。

元のPNGのままだと、40人が一斉に開いたときに合計120MB以上の通信が発生し、
授業のはじめに全員の表示が止まってしまいます。そのため同じ絵をJPEGに変換して使っています
（見た目の差はほとんどありません）。

**PNGに戻したいときは、対応する `.jpg` を削除してください。**

## 推奨サイズ・容量

- 横幅 **1600〜2000px** 程度、横長（3:2 くらい）
- 容量は **400KB 以下**を目安に

> 学校の端末は40人が一斉に開くことがあります。
> 数MBの画像だと、授業のはじめに全員の表示が止まってしまいます。
> WebP か、品質80%程度のJPEGへの変換をおすすめします。

## 見え方の調整

背景の上には、文字を読みやすくするための「暗幕」がかかります。
濃さや位置を変えたいときは `styles/home.css` の次の場所を触ってください。

| 直す場所 | 何が変わるか |
|---|---|
| `body.home.has-bg-art::before` の `background-position` | 絵のどのあたりを画面に出すか（既定: `center 38%`） |
| `body.home.has-bg-art::after` の `background` | 暗幕の濃さ。数値を小さくすると絵がはっきり見えます |
| `body.home.has-bg-art .home-card` の `background` の透明度 | カードの透け具合 |

絵のなかの人物がカードで隠れてしまう場合は、`background-position` の
2つめの数値（`38%`）を小さくすると、絵が下にずれて人物が見えやすくなります。

## 権利について

学校で配布・公開する教材に使う画像です。**使用してよい画像かどうかを必ず確認してください。**
生成AIで作った画像を使う場合も、利用規約と、教材としての表示条件を確認しておくと安心です。
