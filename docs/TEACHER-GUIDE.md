# 先生用ガイド（授業案・ワークシート）

「フェアトレード・チャレンジ ～チョコレートの旅～」を授業で使うための手引きです。

- **対象**: 中学校・高等学校（小学校高学年版は「小学校版」ルールセットを使用）
- **教科**: 社会（地理・公民）／総合的な学習の時間／家庭科／SDGs探究
- **時間**: 1コマ（45〜50分）。ゲーム本体は20〜30分
- **人数**: 1グループ4〜6人（1人1台）。クラス全体では複数ルームを同時に立てられます

---

## 1. この授業のねらい

1. フェアトレードを「良いことだから」ではなく、**価格と経営の問題として**理解する
2. **「フェアトレードと言っているだけの取引」と「国際フェアトレード認証」の違い**を区別できるようになる
3. 会社の成績を「利益」だけで測ってよいのか、自分の言葉で考えられるようになる

> このゲームは「フェアトレードを選べば勝つ」ようには作られていません。
> 認証原料を選んでも、価格や広告の判断を誤れば負けます。
> 逆に、安い原料だけで利益を出しても、総合ランキングでは順位が下がります。
> **正解を教えるのではなく、判断させて、その結果を話し合うための教材**です。

---

## 2. 準備（授業前・5分）

1. ブラウザで `/teacher` を開く（公開先のURL + `/teacher`）
2. 「ルームを作成する」を押す → 6けたの番号とQRコードが表示される
3. その画面をプロジェクタに映す（右上の「拡大表示」で文字が大きくなります）

**予行演習をしておくと安心です。** 「🤖 練習用AIを追加」を4回押してから開始すれば、
先生のPC1台だけで1ゲームを最後まで通せます（3〜5分）。

### 事前に配っておくもの

- ワークシート（このページの末尾。印刷して配布）
- 端末（1人1台）

---

## 3. 授業の流れ（50分）

| 時間 | 場面 | 先生の動き | 問いかけ |
|---|---|---|---|
| 0-5分 | 導入 | チョコレートを見せる／板書「このチョコは誰が作った？」 | 「1枚100円のチョコ。カカオを育てた農家さんには、いくら届いていると思う？」 |
| 5-10分 | ルール説明 | 参加させる。待機画面の「ゲームの進め方」を読む | 「みんなはチョコレート会社の社長です。5年間、どんな会社にしますか？」 |
| 10-32分 | ゲーム（5ラウンド） | 「次へ」を押していく。各年の結果で1〜2問だけ問いかける | 下の「各ラウンドでの問いかけ」参照 |
| 32-38分 | 結果発表 | ①利益 → ②総合 の順に発表 | 「では、社会全体ではどうだったでしょう？」 |
| 38-48分 | ふりかえり | ワークシート記入 → グループで共有 | 下の「ふりかえりの問い」参照 |
| 48-50分 | まとめ | 認証マークの実物・商品を見せる | 「今日の判断を、次に買い物をするときに思い出してください」 |

### 各ラウンドでの問いかけ（1つ選んで30秒程度）

先生用画面の結果ページに、その年に合った **「話し合いのヒント」** が自動で出ます。
そのまま読み上げてもかまいません。

- **1年目（おだやかな年）**: 「まず、どんな会社にするか決まりましたか？」
- **カカオ不作の年**: 「一般市場から買っていた会社は苦しくなりました。**なぜ認証の会社は値上がりしなかったと思いますか？**」
  → 国際フェアトレード基準には「最低価格」の仕組みがあるためです
- **フェアトレードへの関心が高まった年**: 「消費者が変わると、会社の売上も変わりました。**買う人にできることは何でしょう？**」
- **節約志向の年**: 「高い商品が売れなくなりました。良い商品なら高くても売れる、とは限らないようです」
- **赤字の会社が出た年**: 「来年、どうやって立て直しますか？　値段？　原料？」

### 結果発表のしかた（ここが山場）

1. まず **「① 利益ランキング」** だけを見せる。1位を拍手でたたえる
2. ここで **一度止めて**、こう問いかける
   > **「では、社会全体ではどうだったでしょう？」**
3. 「次へ」を押して **「② 総合ランキング」** を出す
4. 順位が入れ替わっていたら、その場で
   > **「なぜ順位が変わったのでしょう？」**

順位が入れ替わらなかった場合も使えます。
> 「1位の会社は、利益と生産者への支払いを、どうやって両立させたのでしょう？」

---

## 4. ふりかえりの問い（ワークシート・グループ共有）

先生用画面の「③ ふりかえり」に、そのまま投影できる問いが出ます。

1. 利益で1位だった会社と、総合で1位だった会社は同じでしたか。違ったなら、それはなぜでしょう。
2. あなたの会社は、どの年にいちばん大きな決断をしましたか。その理由は何でしたか。
3. 一般市場・直接取引・国際フェアトレード認証の3つは、何がどう違いましたか。
4. 「フェアトレードだと言っている商品」と「国際フェアトレード認証を受けた商品」の違いを、他の人に説明できますか。
5. 会社が生産者に多く支払うと、利益は減ります。それでも支払うべきだと思いますか。
6. あなたが実際にお店でチョコレートを買うとき、何を基準に選びますか。今日、その基準は変わりましたか。

### 発展的な問い（高校・探究向け）

- 「安く買ったうえで一部を寄付する」のと「はじめから公正な価格で買う」のでは、生産者にとってどちらが良いでしょうか。
  （ゲームでも、前者の戦略はあまり勝てないようになっています）
- 認証を受けるには生産者組合にも費用と手間がかかります。それでも認証を取る理由は何でしょうか。
- 会社の成績を測る「ものさし」を自分で作るとしたら、何を何%で評価しますか。

---

## 5. 授業中に困ったときは

| 困ったこと | 対処 |
|---|---|
| 生徒が入れない | 番号の桁を確認（6けた）。同じWi-Fiにいるか確認 |
| 1人だけ決まらない | 先生画面の「締め切って結果を出す」で進めてください。未決定の人は既定の選択で計算されます |
| 生徒の画面が固まった | ブラウザを更新すれば同じ会社に戻ります |
| 生徒が抜けてしまった | そのまま続行できます。「🤖 練習用AIを追加」で人数を埋めることもできます |
| 先生の画面を閉じてしまった | `/teacher` を開き直すと「前回のルームに戻る」が出ます |
| 時間が足りない | ラウンド数を減らせます（`config/rules.mvp.json` の `rounds`）。または小学校版（3ラウンド）を使用 |
| ルールが難しそう | 小学校版は決めることが2つだけ（カカオと価格）です。中学生でも導入に使えます |

**制限時間**を使うと進行が読みやすくなります（ルーム作成時に1分〜3分を選択）。
慣れないうちは「なし（先生が締め切る）」のままをおすすめします。

---

## 6. 授業後

先生用画面の **「結果をCSVでダウンロード」** で、全ラウンドの選択と結果を保存できます。
Excel で開けます（ふりかえりの資料、研究授業の記録、教材改善の材料に）。

**「印刷」** ボタンで、最終結果を紙に残すこともできます。
